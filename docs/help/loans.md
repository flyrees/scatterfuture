# 贷款和分期

## 贷款记录

用于记录房贷、车贷、信用贷等有固定还款计划的负债。

1. 进入账本 → 贷款 → 新建贷款。
2. 填写本金、年利率、期数、还款方式（等额本息 / 等额本金）。
3. 保存后系统自动生成每期还款计划，并支持提前还款试算。

::: tip 利率填写
请填写**年化利率**，例如 4.9% 填 `4.9`。若你的合同写的是月利率，请乘以 12。
:::

## 消费分期

对单笔消费做分期，账单会按月摊到各期。

- 支持设置手续费率（一次性 / 按月）
- 每期会自动生成一笔支出记录，可随时修改

## 账单分期

对已有账单做整单分期。

1. 在账单详情页点击「账单分期」
2. 选择期数与手续费方式
3. 确认后原账单会被拆分为多期

## 常见问题

**提前还款后利息怎么算？**

按剩余本金重新计算，已支付的手续费不退还，具体以你的合同条款为准。

**分期会影响预算吗？**

每期产生的支出会正常占用当期预算。
