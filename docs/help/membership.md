# 会员说明

会员（Pro）解锁全部高级功能，并按周期自动续费，具体权益以购买页展示为准。

## 会员能做什么

| 功能 | 免费版 | 会员版 |
| --- | --- | --- |
| 基础记账 | ✅ | ✅ |
| 多账本 | 1 个 | 不限 |
| 高级报表 / 分类统计 | 部分 | 全部 |
| 贷款与分期管理 | ❌ | ✅ |
| iCloud 多设备同步 | ❌ | ✅ |
| 数据导出（CSV / Excel） | ❌ | ✅ |
| 小组件主题 | 默认 | 全部 |

## 订阅方式与价格

会员通过应用商店内购销售：

- iOS / iPadOS：App Store
- 安卓 / 鸿蒙：对应应用市场

价格以购买时页面展示为准，可能因地区和促销活动有所不同。

## 自动续费说明

订阅成功后，系统会在每个计费周期结束前 24 小时内自动扣费续期。

**如何取消自动续费：**

- **iOS**：设置 → Apple ID → 订阅 → 选择本应用 → 取消订阅
- **安卓 / 鸿蒙**：对应应用市场的「我的 → 订阅管理」中关闭

取消后你仍可使用至当前周期结束，不会立即失效。

## 常见疑问

::: warning 换设备后会员没了？
会员绑定的是你的**商店账号**，不是设备。请在新设备上登录同一个 Apple ID / 应用市场账号，然后点[恢复会员身份](/help/restore-purchase)。
:::

**会员到期后数据会丢失吗？**

不会。你的数据始终保存在本地，会员仅影响功能可用性。到期后高级功能会变为只读或不可用，续费即可恢复。
