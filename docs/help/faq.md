# 常见问题汇总

## 资金与余额

### 资产账户没有更新余额

按顺序检查：

1. **是否记录了转账**：账户余额由「初始余额 + 收入 − 支出 + 转入 − 转出」计算，跨账户转账需要分别记录转出和转入。
2. **是否在正确的账本**：切换账本后余额会随之变化。
3. **是否被归档**：归档的账户默认不计入总资产。
4. 下拉刷新或重启应用。

### 结余结转问题

- 结余结转会把本周期剩余金额带到下个周期，若关闭该功能，每个周期的结余从 0 开始。
- 结转金额为负时按支出处理，可在报表中单独查看。

## 显示与小组件

### 小组件显示异常

1. 长按小组件 → 移除，然后重新添加。
2. iOS 上小组件刷新有系统限制（通常 15 到 30 分钟一次），可点进应用触发刷新。
3. 确认小组件选择的账本存在于当前设备。

### Apple Watch 获取不到分类 / 账本 / 货币等数据

- 打开 iPhone 上的应用，进入 Watch App 同步一次数据。
- 确认 Watch 与 iPhone 已连接同一 Wi-Fi 或蓝牙。
- 若仍为空，在 Watch 上删除应用后重新安装。

## 同步与数据

### 数据不同步到其他设备

见 [iCloud 云同步](/help/icloud) 中的排查步骤。

### 卸载应用后数据还在吗？

本地数据会随卸载删除。如果开启了 iCloud 同步或导出过备份，重新安装后可以恢复。

### 可以导出数据吗？

会员可通过「设置 → 数据 → 导出」生成 CSV / Excel 文件。免费用户可导出账本截图。
