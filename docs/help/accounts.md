# 多账本

## 多账本功能

用多个账本分别管理不同场景，例如：日常、家庭、旅行、公司。

- 各账本的分类、预算、账户相互独立
- 顶部可快速切换账本
- 总资产视图可跨账本汇总

> 免费版支持 1 个账本，会员不限数量。

## 账本归档

不再使用的账本可以归档，而不是删除。

- 归档后不出现在切换列表中，但数据保留
- 归档账本不计入总资产统计
- 可在「账本管理 → 已归档」中恢复

## 账本复制

复制账本会生成一个结构相同的新账本。

用途：

- 做年度账本时保留分类和账户结构
- 为家人创建配置相同的账本

复制选项：

| 选项 | 说明 |
| --- | --- |
| 仅结构 | 复制分类、账户、预算，不复制记录 |
| 结构与记录 | 完整复制，适合做数据备份副本 |
| 结构与最近记录 | 复制结构 + 最近 N 个月记录 |

::: warning 复制不可撤销
复制会立即占用存储空间，确认前请留意目标账本名称。
:::
