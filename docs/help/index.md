## 还是没解决？

通过应用内的 **「设置 → 建议与反馈」** 联系我们，并附上：

- 问题描述和你期望的结果
- 应用版本号（设置页底部可查看）
- 设备型号与系统版本
- 相关截图或录屏

我们通常在 1 到 2 个工作日内回复。
