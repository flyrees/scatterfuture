# 绑定购买信息到安卓 / 鸿蒙

在 iOS 上购买过会员，换到安卓或鸿蒙设备后，可以把购买记录绑定过去继续使用。

## 前提条件

- 你之前在 iOS 上**购买过且未退款**的会员订单
- 安卓 / 鸿蒙设备上已安装最新版本
- 两端都已登录同一个应用账号（如产品无账号体系，请见下方说明）

## 操作步骤

1. 在安卓 / 鸿蒙设备打开应用 → 设置 → 会员 → 「**绑定已有购买**」。
2. 选择「从 iOS 迁移」。
3. 输入 iOS 端购买的**订单号**（可在 App Store 购买记录中查看）。
4. 提交后等待校验，通常 1 分钟内完成。

::: tip 关于账号体系
如果你的产品没有登录体系，绑定是基于设备与订单号的校验，一个订单只能绑定一次。建议在绑定前先完成数据迁移（见[数据备份和恢复](/help/backup)）。
:::

## 常见问题

**提示"订单不存在或已绑定"？**

- 核对订单号是否完整（通常以 `M` 开头的一串字符）
- 该订单可能已绑定过其他设备，请联系我们解绑

**绑定后有效期怎么算？**

跟随原订单的剩余有效期，不会重新计算。
