# iCloud 云同步

iCloud 同步让你的多台 Apple 设备保持数据一致。它是 Apple 提供的系统级服务，数据存在**你自己的 iCloud 空间**里，我们不经过服务器。

## 开启同步

1. 确认设备已登录 iCloud：设置 → 你的名字。
2. 设置 → 你的名字 → iCloud → 确保「**iCloud 云盘**」已开启。
3. 打开应用 → 设置 → 同步 → 开启「iCloud 同步」。
4. 首次同步建议保持应用在前台，等待进度条完成。

> 同步需要会员权限。

## 同步规则

- 同一 iCloud 账号下的多台设备自动合并数据。
- 冲突时以**最后修改时间**为准。
- 删除操作也会同步，删除前请确认。

## 排查：iCloud 不可用

### iPhone / iPad

1. 设置 → 你的名字 → iCloud → 查看存储空间是否已满（满了会停止同步）。
2. 退出 iCloud 账号后重新登录（注意先备份）。
3. 关闭再开启应用的 iCloud 开关（设置 → 你的名字 → iCloud → 使用 iCloud 的 App）。

### Mac

1. 系统设置 → Apple 账户 → iCloud → iCloud 云盘 → 确认应用在列表中且已勾选。
2. 检查 `~/Library/Mobile Documents/` 下是否生成了应用目录。
3. 重启 Finder：按住 Option 右键 Dock 中的 Finder → 重新开启。

## 同步报错排查

| 报错 | 原因 | 处理 |
| --- | --- | --- |
| 未登录 iCloud | 系统账号未登录或已过期 | 重新登录 Apple ID |
| 存储空间不足 | iCloud 容量已满 | 清理空间或升级方案 |
| 网络受限 | 代理或防火墙拦截 | 关闭代理后重试 |
| 数据冲突 | 多设备同时修改 | 等待自动合并，或手动选择保留版本 |

::: warning 重要
同步不能代替备份。建议定期使用[数据备份和恢复](/help/backup)导出完整备份。
:::
