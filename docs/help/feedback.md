# 建议与反馈

我们很希望听到你的想法。无论是功能建议、体验吐槽还是 Bug 反馈，都欢迎告诉我们。

## 反馈渠道

- **应用内**：设置 → 建议与反馈（推荐，会附带设备信息）
- **邮件**：【support@example.com】
- **社群**：【QQ / Telegram / 微信群链接】

## 怎样提交一条有效的反馈

一条好反馈通常包含这几点：

1. **发生了什么**：例如"点击导出 CSV 后应用闪退"。
2. **期望是什么**：例如"期望弹出保存到文件的对话框"。
3. **复现步骤**：从打开应用到出问题的每一步。
4. **环境**：应用版本、系统版本、设备型号。
5. **证据**：截图或录屏。

## 处理时效

- 一般咨询：1 到 2 个工作日
- Bug 反馈：确认后会进入排期，修复版本会在[更新记录](/help/changelog)中说明

::: tip 关于数据
反馈中请勿附带银行卡号、身份证号等敏感信息。若需要提供账本数据，请先脱敏。
:::
