# 数据备份和恢复

换手机、重装应用前，请务必先做一次备份。

## iOS

### 开启 iCloud 自动备份

1. 设置 → 你的名字 → iCloud → iCloud 云备份 → 打开「iCloud 云备份」。
2. 点击「立即备份」。
3. 确认备份列表中显示本应用的数据。

### 恢复或迁移记账数据

- **整机恢复**：新设备激活时选择「从 iCloud 云备份恢复」。
- **单应用恢复**：先在旧设备做一次完整备份，再在新设备登录同一 Apple ID，打开应用 → 设置 → 数据 → 从备份恢复。

## 安卓

### 恢复或迁移记账数据（安卓 / 鸿蒙）

1. **旧设备**：设置 → 数据 → 导出备份，生成 `.bak` 文件，保存到本地或云盘。
2. **新设备**：安装应用 → 设置 → 数据 → 导入备份 → 选择该文件。
3. 导入完成后重启应用，检查账本数量与余额是否正确。

::: tip 文件放哪
备份文件是完整的本地数据库快照，**请勿通过聊天软件直接发送**（可能被压缩损坏）。建议使用文件管理器、网盘或数据线传输。
:::

## HarmonyOS

- 支持通过「应用市场 → 我的 → 云备份」恢复应用数据。
- 也支持上述 `.bak` 文件的导入导出方式。

## 备份建议

- **频率**：至少每月一次，重要操作（批量删除、合并账本）前一次。
- **异地**：不要只存在一台设备上。
- **验证**：备份后在新设备试导入一次，确保文件可用。
