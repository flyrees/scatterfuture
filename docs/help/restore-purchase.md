# 恢复会员身份

换了新设备、重装了应用，或者会员权益没有自动生效时，可以用「恢复购买」找回已付费的权益。

## 操作步骤

1. 确认新设备已登录**购买时使用的同一个商店账号**（Apple ID / 华为账号等）。
2. 打开应用 → 设置 → 会员 → 点击「**恢复购买**」。
3. 等待几秒，权益会自动同步。

## 恢复失败的排查

按顺序尝试：

1. **确认账号一致**：App Store 的账号可能和 iCloud 账号不同，请检查「设置 → 你的名字 → 媒体与购买项目」。
2. **检查网络**：恢复购买需要连接商店服务器，请关闭代理后重试。
3. **重新登录商店账号**：退出后重新登录，再点恢复购买。
4. **确认订单未被退款**：如已申请退款，权益会被系统收回。
5. **等待 24 小时**：极少数情况下订单状态同步有延迟。

## 仍然失败？

请把**购买凭证**发给我们：

- iOS：App Store → 右上角头像 → 购买记录 → 找到对应订单 → 截图
- 安卓 / 鸿蒙：对应应用市场的订单详情页截图

发送至【support@example.com】，注明你的应用版本和问题描述，我们会人工补发权益。
