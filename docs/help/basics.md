# 基础功能

## 转账手续费 / 优惠功能

记录跨账户转账时，可以附带手续费与优惠：

- **手续费**：作为独立支出或计入转账成本
- **优惠**：从实际支出中抵扣，例如满减、立减

在转账页面展开「更多选项」即可设置。

## 消费优惠功能

单笔消费支持叠加优惠：

1. 记一笔支出
2. 点击「优惠」，填写减免金额
3. 实际支出 = 原价 − 优惠

优惠金额会在报表中单独统计，方便查看"省了多少钱"。

## 账单批量操作

在账单列表中长按或点击右上角「多选」：

- 批量修改分类
- 批量修改账户
- 批量删除
- 批量移动到期数（分期账单）

::: tip 批量删除前
建议先[备份数据](/help/backup)。批量删除不可撤销。
:::
